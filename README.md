# 🎰 今天吃什麼

用扭蛋機決定下一餐的單檔網頁（`index.html`），直接用瀏覽器開啟即可，不需要安裝任何東西。

## 解決的痛點
每餐都要花時間煩惱吃什麼，而且常常重複吃同樣的東西。

## 功能
- 依餐別、預算、心情篩選，扭蛋機隨機決定
- 避免連吃同類型（近 3 天已吃過 2 天的類型先跳過）
- 超過 580 道菜色（台灣 220 多道，其他 20 個地區各 13 道以上）、21 個地區風味（台灣、日本、韓國、義大利、泰國、墨西哥、法國、印度、美國、越南、香港、中國、西班牙、德國、土耳其、希臘、馬來西亞、印尼、巴西、摩洛哥、英國）
- 依餐別自動換風格：早餐＝可愛動物、午餐／晚餐＝各國風格（料理也跟著換）、宵夜＝復古霓虹
- 可固定機台風格：經典、動物、霓虹、科技、各國隨機或單一國家
- 揪朋友投票、分享結果
- 自訂口袋名單、排除不想吃的、吃過紀錄（皆存在瀏覽器 localStorage）
