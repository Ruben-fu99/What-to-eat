# 🎰 今天吃什麼

用扭蛋機決定下一餐的單檔網頁（`index.html`），直接用瀏覽器開啟即可，不需要安裝任何東西。

## 解決的痛點
每餐都要花時間煩惱吃什麼，而且常常重複吃同樣的東西。

## 功能
- 依餐別（早餐／午餐／晚餐／宵夜／甜點）、預算、心情篩選，料理嚴格對應所選餐別（早餐只出早點、宵夜只出小吃／炸烤等、甜點只在甜點餐別出現），扭蛋機隨機決定
- 扭蛋稀有度：普通 60%、稀有 25%、超稀有 11%、傳說 4%，不同稀有度有不同的開蛋特效（光暈、彩紙、閃光、震動、流星）
- 避免連吃同類型（近 3 天已吃過 2 天的類型先跳過）
- 超過 880 道菜色（台灣 300 道左右，宵夜 420 多道）、35 個地區風味（台灣、日本、韓國、義大利、泰國、墨西哥、法國、印度、美國、越南、香港、中國、西班牙、德國、土耳其、希臘、馬來西亞、印尼、巴西、摩洛哥、英國、新加坡、菲律賓、柬埔寨、尼泊爾、秘魯、阿根廷、葡萄牙、瑞士、波蘭、俄羅斯、黎巴嫩、衣索比亞、澳洲、加拿大），每個國家都是一個機台主題
- 依餐別自動換風格：早餐＝可愛動物、午餐／晚餐／甜點＝各國風格（料理也跟著換）、宵夜＝復古霓虹
- 可固定機台風格：經典、動物、霓虹、科技、各國隨機或單一國家
- 轉蛋音效（瀏覽器即時合成，可關閉）、依稀有度變化的音效與特效
- 揪朋友投票、分享結果
- 自訂口袋名單、排除不想吃的、吃過紀錄（皆存在瀏覽器 localStorage）
